# Dra. Juliana Diniz - Landing Page

Clone fiel 100% autônomo do template Clireo, otimizado para LiteSpeed e deploy na Hostinger.

## Subdomínio de Destino
- **URL**: `https://drajulianadiniz.landingprofile.com/`

## Estrutura do Projeto
- `index.html`: Página principal com assets locais e scripts nativos.
- `.htaccess`: Configuração de segurança, cache e compressão Brotli/Gzip para LiteSpeed / Apache.
- `assets/css/interactions.css`: Animações nativas (marquee, cards, scroll reveal).
- `assets/js/interactions.js`: Lógica nativa de carrossel, FAQ accordion, formulário e duplicador de marquee.
- `assets/images/`: 41 imagens e SVGs locais de alta resolução.
